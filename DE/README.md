## Reproduce everything
```bash
export PGHOST=localhost PGUSER=<user> PGPASSWORD=<password>
createdb museumx
./run_all.sh museumx        # builds the schema, loads data, runs all SQL and the Node demo, rewrites evidence/
```
Requires PostgreSQL 14+ and Node.js 18+.

## Before you submit: checklist
- [ ] **Verify `sql/schema.sql` against your real `schema.prisma`.** It is a hand translation of the Prisma models (Prisma-style quoted names) and was run on PostgreSQL 16, but was not generated by Prisma. Compare with `npx prisma migrate diff --from-empty --to-schema-datamodel server/prisma/schema.prisma --script`.
- [ ] **Align status strings** in `sql/constraints_and_indexes.sql` with what your Express code writes (`CONFIRMED`, `SUCCESS`, `USED`, ...).
- [ ] **Fill in real route names** in `docs/07_database_backend_integration.md` and test `backend_integration/bookingService.prisma.js` in your project.
- [ ] **Add screenshots** (app UI and Prisma Studio or Neon console showing the same rows) to `evidence/`.
- [ ] Never commit `.env`, database URLs or Razorpay keys. Sample password hashes here are placeholders.
- [ ] Every member reads `docs/10_viva_preparation.md` and can run `./run_all.sh`.
